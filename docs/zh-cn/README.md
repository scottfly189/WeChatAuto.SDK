# DroidMirror简介

!> 无需安装APP,无需ROOT权限，即可投屏与操控，支持自动滑动、自动操作、OCR识别,输入不再局限于手指,小屏不再定义体验 - 你有更自由的手机娱乐新方式

## 🚀 核心特性

**1. 高清投屏（可调参数）**: 支持自定义分辨率、码率、帧率等关键参数，实现高质量、低延迟的画面传输,适用于应用演示、远程教学、自动化测试、录屏制作等多种场景。

**2. 多屏扩展（多窗口运行）**: 支持单设备扩展为多个独立窗口，实现多屏分控,可同时运行不同应用，显著提升多任务处理效率，适用于运营、测试及批量操作场景。

**3. 电脑输入直通（增强交互）**:支持将电脑键盘输入直接映射至手机，无需频繁点击屏幕,同时支持自动滑动、自动点击发送等操作，大幅提升输入与交互效率，特别适用于聊天、数据录入等场景。

**4. Google 服务一键检测与安装支持**: 可检测设备是否支持 Google 服务框架（GMS），并提供安装支持方案,帮助用户在受限网络环境下使用主流应用，如 Google、YouTube、Gmail 等。

**5. 智能骚扰电话拦截（开发中）**: 提供可选功能模块，自动拦截非通讯录或自定义名单外的来电,有效应对 AI 外呼、营销电话等骚扰场景，让你专注在当前工作。

# 🔌 接入教程

在使用 DroidMirror 之前，需要让电脑能够“识别并控制你的手机”。  
这个过程依赖 Android 的一个官方功能：打开**开发者调试**功能。

👉 别担心，这不复杂，只需要简单设置一次即可。

---

## 🔗 USB接入

这是**最稳定、最简单**的方式，推荐第一次使用选择。

你的手机必须开启：

- ✅ 开发者模式  
- ✅ USB 调试
  
否则 **无法连接成功**。

---

##### 🧭 第一步：开启开发者模式（只需一次）
不同手机略有差异，但大致步骤如下：
1. 打开手机 **设置**
2. 找到 **关于手机**，点击进入子菜单
3. 找到"设备标识符"（注：可能有些手机不需要此步骤）,点击进去，找到**“版本号”**
4. 连续点击 **“版本号” 7 次**
5. 输入锁屏密码（如果有）
6. 出现提示：✅ *“您已进入开发者模式”*

---

##### 🔧 第二步：开启 USB 调试
1. 返回 **设置**
2. 进入 **开发者选项**
3. 找到并打开：
   - ✅ USB 调试（USB Debugging）
4. 如果你的手机有弹窗，请点击“允许”

---

##### 🎉 成功开启“开发者模式”后，打开DroidMirror,即可自动识别设备
