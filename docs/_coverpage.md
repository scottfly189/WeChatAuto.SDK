## **WECHATAUTO.SDK - 安全构建微信 Agent 的开发基座**

不注入、双路径、安全构建

微信是应用，WeChatAuto.SDK 是开发微信自动化应用的开发包。

这是一个面向开发者的微信自动化开发工具包，帮助你构建自己的微信机器人、微信助手和 AI Agent。

本仓库是社区开源版，用 UI Automation 操作真实微信，可先跑监听、发送、好友、群等基础能力。

❌ 不注入、不修改微信客户端

💯 社区开源版用 UIA 操作真实微信，可先上手

💯 源码公开、透明、不留任何后门

💯 让你的微信 Agent/Wechat Bot 快速开发、快速上线、并安全发布到用户端
