强开 UI Tree。

通过向正在运行的微信(Weixin)进程的 Qt 无障碍“门控字节”写入 1，强制微信公开 UI Tree。 该工具不会启动微信、不会注入代码、不会修改内存页保护，只会写入 Weixin.dll 中 那一个已存在的 Qt 无障碍状态字节，并在写入前校验进程、模块、PE 节、扫描证据与当前字节值。

本类移植自 qt_accessibility_activator.py。

public ForceOpenUITree.ActivationResult ForceOpen(int? pid = null, bool checkOnly = false, bool verifyUia = true, double uiaTimeoutSeconds = 5)

Parameters

pid int?

要针对的微信进程 PID；为 null 时自动探测第一个符合条件的微信进程（PID 最小者）。

checkOnly bool

为 true 时仅读取门控字节并做 UIA 验证，不写内存。

verifyUia bool

为 true 时在操作后执行一次 UIA 验证（对应 Python 的 --no-uia-verify 取反）。

uiaTimeoutSeconds double

UIA 验证的最长等待秒数（默认 5 秒，下限 0.1 秒）。

Returns

ForceOpenUITree.ActivationResult

执行结果，参见 ForceOpenUITree.ActivationResult。

Exceptions

WechatNotOpenedException

未找到符合条件的微信进程（或指定 PID 不可用）。

InvalidOperationException

打开进程、读写内存或读回验证失败。
