    WeChatDatabase

    SQLCipher 会话层：面向"整个账号"的直读入口。

    打开时解析账号与密钥，但**不立刻连接**任何库；调用 Connect(string, bool) 时， 先用一致拷贝把 .db + -wal（不拷 -shm）复制到 db_storage **之外**的 staging 目录，再在副本上开 SQLCipher，把连接交给调用方。 因此微信可以继续运行，直播库也不会被长期占用。

    调用方自己写 SQL，并在用完后 Dispose 连接（文件锁释放后才能对该库再次 Connect(string, bool) / 重新旁路拷贝）。生命周期由调用方负责：会话的 Dispose() 会关闭仍未释放的连接，并删除自动创建的 staging 目录。

    WeChatDecryptor

    数据库解密门面：把微信 4.x（SQLCipher / WCDB）的加密数据库解密成普通 SQLite。

    覆盖三种粒度：单库解密（DecryptFile(DecryptFileOptions)）、整账号批量解密（DecryptAll(DecryptAllOptions)）、 以及不落盘只验密钥（Verify(VerifyKeyOptions)）和列出待解库（ListDatabases(string)）。

    所有方法只读源库、只写 --out 指定的输出目录；不会修改微信自己的 db_storage。

    WeChatDisplayName

    联系人显示名。Remark 优先，空则 NickName；都空则空串。 不使用 Alias（那是微信号）或 username（已在业务键里）。

    WeChatHotSync

    在线热同步门面（hot-sync）：微信不用退出也能读库。

    两条路径共用旁路一致快照（.db + -wal，从不拷 -shm，拷到 db_storage **之外**的 staging，指纹稳定后才继续）：

    1. Sync(HotSyncOptions) / Watch(HotSyncWatchOptions)：staging 副本 → 页解密 → 明文镜像目录；
    2. OpenSqlCipher(HotSyncSqlCipherOptions)：staging 副本 → SQLCipher 直读（不落明文），再 Connect(string, bool) 拿连接、自写 SQL。

    默认目标集（P0）为 message/message_*.db + sns/sns.db； IncludeContact 可追加 contact/contact.db（见 ListTargets(string, bool)）。 session/session.db 不在拷贝和监视范围内。 全程只读微信目录、不写回。

    WeChatKeyRecovery

    获取 key 门面：从运行中的微信进程恢复数据库密钥（仅 Windows x64）， 以及"昵称 / wxid → 账号目录 → db_storage"的定位辅助。

    原理：扫描 Weixin.dll 里的 32 字节 internal_db_key 掩码 + 微信进程内存里的密钥指针， 把每个候选做 XOR 解掩码后，用真实库的首页 HMAC 校验，命中即真密钥。 全程只读 DLL 与进程内存：不注入、不 Hook、不改微信内存，但杀软/EDR 可能按行为告警。

    前置条件：微信已启动并登录；本进程与微信同一权限级别（微信用管理员运行时本进程也需提权）。

    WeChatMedia

    媒体文件门面：解密微信 4.x 的图片/视频/语音，以及解析媒体密钥（image key）。

    媒体密钥与数据库密钥是**两套独立**的：数据库 key 解 .db，媒体 key（1 字节 XOR + 16 字符 AES）解 .dat / .wxgf。本类先尝试本地 kvcomm 侧车解析， 必要时再扫描微信进程内存。

    纯本地操作：只读文件（或只读进程内存），不联网。

    WeChatSqlCipher

    SQLCipher 直读（低层门面）：直接用 SQLCipher 引擎打开一个加密数据库文件并查询， 不经过"解密成明文 SQLite 文件"的路径。

    适合"只想看几张表 / 几行"的场景：不产出明文文件，磁盘上不留解密副本。 引擎为 Microsoft.Data.Sqlite.Core + SQLitePCLRaw.bundle_e_sqlcipher （SQLCipher 4 原生库）；SQLCipher 是 SQLite 超集，明文库也能用同一套 API 打开。

    注意：本类的 Open(string, WeChatKey, string?, bool) 直接打开**给定路径**， 不会自动做旁路拷贝。要读正在被微信占用的直播库，请用会话层 WeChatDatabase（它会先一致拷贝到 staging 再打开）。

    调用方自己写 SQL、自己管连接生命周期：Open 返回已解锁的 SqliteConnection，用 using / Dispose 关掉后文件锁即释放 （默认 Pooling = false），便于随后拷贝或替换这份 clone。
