    Class WeChatSqlCipher

    SQLCipher 直读（低层门面）：直接用 SQLCipher 引擎打开一个加密数据库文件并查询， 不经过"解密成明文 SQLite 文件"的路径。

    适合"只想看几张表 / 几行"的场景：不产出明文文件，磁盘上不留解密副本。 引擎为 Microsoft.Data.Sqlite.Core + SQLitePCLRaw.bundle_e_sqlcipher （SQLCipher 4 原生库）；SQLCipher 是 SQLite 超集，明文库也能用同一套 API 打开。

    注意：本类的 Open(string, WeChatKey, string?, bool) 直接打开**给定路径**， 不会自动做旁路拷贝。要读正在被微信占用的直播库，请用会话层 WeChatDatabase（它会先一致拷贝到 staging 再打开）。

    调用方自己写 SQL、自己管连接生命周期：Open 返回已解锁的 SqliteConnection，用 using / Dispose 关掉后文件锁即释放 （默认 Pooling = false），便于随后拷贝或替换这份 clone。

    Open(string, WeChatKey, string?, bool)

    打开一个微信 4.x 加密数据库并返回已解锁的 SQLCipher 连接（调用方负责 Dispose）。

    Declaration
    public static SqliteConnection Open(string dbPath, WeChatKey key, string? mode = null, bool readWrite = false)
    Parameters
    Type Name Description
    string dbPath

    数据库文件路径（建议传 staging 副本，而不是微信正在写的直播文件）。
    WeChatKey key

    数据库密钥（32 字节 / 64 位 hex）。
    string mode

    强制密钥形态："raw"（密钥本身就是每库 AES key）或 "passphrase" （密钥是口令，需再走 PBKDF2 256 000 轮）。传 null 表示自动：先 passphrase （WeChat 4.x 的实际用法）再 raw，各自再分别尝试 cipher_compatibility=4 与库默认值，共 4 种组合。成功的组合会在第一次尝试命中，避免无效打开刷异常。
    bool readWrite

    默认 false：以 ReadOnly 打开（只读查询 clone 的推荐方式）。 传 true 才以 ReadWrite 打开，仅应对 staging 副本写入。
    Returns
    Type Description
    SqliteConnection

    打开成功的 SqliteConnection，可直接 CreateCommand() 跑自己的 SQL。
    Remarks

    判定"打开成功"的标准是 SELECT count(*) FROM sqlite_master 能读出结果—— SQLCipher 的 PRAGMA key 本身不校验密钥，第一次读页时才校验。 打开后可调用 OpenMeta(SqliteConnection) 查看实际命中的形态。 连接以 Pooling = false 打开；Dispose 后文件锁释放，外面可再拷贝/替换该文件。

    Exceptions
    Type Condition
    SqlCipherReaderException

    文件不存在、密钥长度不对，或 4 种组合全部失败（密钥不属于该库、文件不是 SQLCipher 4 库、 文件损坏等）。异常消息里带每种组合的失败原因。
