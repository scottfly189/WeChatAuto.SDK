    Remarks

    规则：

    1. 如果存在连续 Equal >= minEqualCount，则认为新旧快照属于同一个消息序列。
    2. 取最后一个满足条件的 Equal Block 作为可靠锚点。
    3. 返回可靠锚点之后的 Insert 消息。
    4. 如果不存在可靠锚点，则认为新旧快照属于完全不同的消息序列，返回整个 newList。
