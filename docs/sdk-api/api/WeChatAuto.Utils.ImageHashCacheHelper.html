    ComputeDHash(Mat)

    计算 Mat 的 dHash（差分感知哈希）。 先转灰度，再裁出文字包围盒（去掉四周/右侧大量空白），只对文字区域缩放到 (HashWidth+1) x HashHeight 后计算 dHash。 空白是串号的元凶：整条昵称里空白占绝大多数时，阈值会被空白稀释、文字差异被淹没，导致不同昵称的哈希趋同。 裁掉空白后框内只有文字，缩放只做 DPI 归一化与低通滤波，不会再把文字稀释掉。 若裁剪图完全没有文字（全空白），返回 null，表示不参与缓存匹配。 注意：本方法只读取传入的 Mat，不会修改或释放它，调用方后续可继续使用原图。
