    MaxWalOnlyRetries

    指纹抖动时「只重拷 WAL」的总次数上限（跨整库重试累计）。

    大库（GB 级）整库拷贝要几十秒，期间微信只要写一次 WAL，指纹就不一致； 原来的实现会整库重拷最多 8 次。这里在「主库字节未变、只有 WAL 变」时只重拷 4MB 级 WAL， 把重试成本从「分钟级 × N」降到「毫秒级 × N」；主库一变仍整库重拷。
