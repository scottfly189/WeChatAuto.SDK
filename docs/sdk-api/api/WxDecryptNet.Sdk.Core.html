    DbErrors

    SQLite / SQLCipher 错误的分类。

    只回答一个问题：这个异常是否意味着**库本身损坏或密钥/副本错位**（而不是锁冲突、IO 忙、SQL 语法错）。 调用方据此决定「丢弃 staging 副本、重新一致拷贝」还是「原样重试」。

    典型来源：staging 副本被 checkpoint 撕裂、SQLCipher 页面 HMAC 不匹配、WAL 与主库世代错位、 或者密钥不对（SQLCipher 会把「密钥错误」表现为 file is not a database）。

    WxProcessAccountMap

    把「正在运行的微信进程」映射到它自己的账号目录（不依赖昵称/明文侧车）。

    原理：微信 4.x 每个账号的主进程会长期持有本账号 db_storage 下 contact.db / session.db / message_0.db 等文件的句柄， 通过 Windows Restart Manager（rstrtmgr.dll）查询“谁打开了这个文件”， 即可得到精确的 pid → 账号目录绑定。

    只读查询，不读微信内存；任何原生失败都返回“未知”，由调用方回退。

    WxRegionNames

    微信 extra_buffer 地区字段（#6 省 / #7 市）的英文 → 中文映射。 命中返回值；未命中返回原串（去掉首尾空白），空输入返回空串。
