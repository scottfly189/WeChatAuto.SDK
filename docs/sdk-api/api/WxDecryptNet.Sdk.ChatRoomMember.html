    Class ChatRoomMember

    一个群的一名成员（FetchChatRoomMembers(string?) 或 ParseChatRoomExtBuffer(byte[]?)）。 群名片与邀请人 username 来自 ext_buffer。群名称、群主/成员/邀请人显示名请关联 contact，本对象不携带这些快照。
