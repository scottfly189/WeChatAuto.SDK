按单个微信号查询中间表（Database Read）。 默认方法都会带上构造时传入的 FromWechatWxId；跨账号搜索请用 SearchAllMessages(string, string)，复杂查询请用 Query(string) 自行写 SQL。 通常通过 WeChatClient 的同名方法调用；单元测试可以直接构造本类型。

HasOutgoingMessageAfter(string, long)

当前微信号指定会话中，是否出现 SortSeq 大于 afterSortSeq 且 IsSelf == true 的消息。 按 ChatUsername 限定会话：只能说明「这个 username 的会话里出现了自己发出的新记录」， 不能在发出前阻止同名误点；若点错了人，本方法应返回 false（消息可能已经发到别人）。

Query(string)

执行用户传入的 SELECT 查询，并把结果做成字典列表返回（不用 DataTable，方便调用方解析或序列化）。 这是给复杂查询预留的通用入口，SQL 由调用方自行编写，本方法不会自动追加 FromWechatWxId 条件。 只支持 SELECT（含 WITH ... SELECT）。中间表由同步写入，在这里做增加、修改或删除没有意义，这类语句会抛出异常。
