    Class WeChatDatabase

    SQLCipher 会话层：面向"整个账号"的直读入口。

    打开时解析账号与密钥，但**不立刻连接**任何库；调用 Connect(string, bool) 时， 先用一致拷贝把 .db + -wal（不拷 -shm）复制到 db_storage **之外**的 staging 目录，再在副本上开 SQLCipher，把连接交给调用方。 因此微信可以继续运行，直播库也不会被长期占用。

    调用方自己写 SQL，并在用完后 Dispose 连接（文件锁释放后才能对该库再次 Connect(string, bool) / 重新旁路拷贝）。生命周期由调用方负责：会话的 Dispose() 会关闭仍未释放的连接，并删除自动创建的 staging 目录。

    Open(SqlCipherSessionOptions)

    打开一个账号会话：解析 db_storage、加载密钥、准备 staging 目录并扫描库存。

    Declaration
    public static WeChatDatabase Open(SqlCipherSessionOptions options)
    Parameters
    Type Name Description
    SqlCipherSessionOptions options

    SqlCipherSessionOptions：

    • PathOrAccountDir：账号路径（db_storage / wxid 目录 / 数据根目录），可空—— 为空时用 Nickname/Wxid 在默认根目录下查找；
    • Nickname/Wxid：账号选择器，规则同 ResolveDbStorage(string, string?, string?, string?, int?)；
    • Key 与 KeyFile：二选一（都传时以 Key 优先）；KeyFile 是含 64 位 hex 的文本文件；
    • VssSource / LiveSource：VSS 优先、live 兜底；不再做 staging 拷贝。
    Returns
    Type Description
    WeChatDatabase

    已 Start() 的会话对象；用完必须 Dispose()。
    Remarks

    这里不做任何数据库连接，只是解析 + 建目录，所以很快；真正的拷贝与解锁发生在 Connect(string, bool)（每次 Connect 都会重新一致拷贝该库）。

    Exceptions
    Type Condition
    ArgumentNullException

    options 为 null。
    SqlCipherSessionException

    路径无法解析、多账号有歧义、既没给 Key 也没给 KeyFile、密钥格式错误、 或 staging 目录落在 db_storage 内部时抛出。
