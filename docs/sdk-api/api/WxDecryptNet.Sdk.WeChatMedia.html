    Class WeChatMedia

    媒体文件门面：解密微信 4.x 的图片/视频/语音，以及解析媒体密钥（image key）。

    媒体密钥与数据库密钥是**两套独立**的：数据库 key 解 .db，媒体 key（1 字节 XOR + 16 字符 AES）解 .dat / .wxgf。本类先尝试本地 kvcomm 侧车解析， 必要时再扫描微信进程内存。

    纯本地操作：只读文件（或只读进程内存），不联网。

    DecryptDirectory(MediaDecryptOptions)

    批量解密一个目录下的媒体文件（只处理 .dat / .wxgf），保持相对目录结构镜像到输出目录。

    Declaration
    public static MediaDecryptResult DecryptDirectory(MediaDecryptOptions options)
    Parameters
    Type Name Description
    MediaDecryptOptions options

    MediaDecryptOptions：

    • Path：要扫描的目录（必填）；
    • XorKey/AesKey：媒体密钥，语义同 DecryptFile(MediaDecryptFileOptions)；
    • OutputDir：输出根目录（必填），相对路径会原样保留；
    • Recursive：默认 true，递归子目录；
    • ConvertWxgf：默认 true，尝试把 wxgf 转 JPEG；
    • Progress：进度回调 (已完成, 总数, 源路径, 是否成功, 失败原因)；
    • Log：细节日志回调。
    Returns
    Type Description
    MediaDecryptResult

    MediaDecryptResult：Total 扫描到的媒体文件数； Success 成功写出数；Failed 抛异常的文件数； Skipped 无法识别的文件数（通常意味着密钥不对或不是加密媒体）； Files 为逐文件明细。
    Remarks

    单个文件失败不会中断整批（异常被计入 Failed，识别不出计入 Skipped）； 目录不存在属于调用方错误，直接抛异常。

    Exceptions
    Type Condition
    ArgumentNullException

    options 为 null。
    DirectoryNotFoundException

    options 的 Path 不存在。

    DecryptFile(MediaDecryptFileOptions)

    解密单个媒体文件（.dat / .wxgf）。

    Declaration
    public static MediaDecryptFileResult DecryptFile(MediaDecryptFileOptions options)
    Parameters
    Type Name Description
    MediaDecryptFileOptions options

    MediaDecryptFileOptions：

    • SourcePath：源文件（必填，只读）；
    • XorKey：媒体 XOR 字节（0..255）；不传时按文件头魔数猜测（V0/V1 常见）；
    • AesKey：16 字符 AES 密钥（V2 图片需要）；不传时只能解非 V2；
    • OutputPath：输出文件；为空时写到源文件旁、扩展名按识别结果自动决定；
    • ConvertWxgf：默认 true，解出 .wxgf（HEVC 流）后尝试用 ffmpeg 转 JPEG；
    • Log：进度回调。
    Returns
    Type Description
    MediaDecryptFileResult

    MediaDecryptFileResult：成功时 Success=true，MediaType 为 image/png|jpeg|gif|webp、video/mp4 或 application/x-wxgf； RawWxgf 表示拿到的是未转码的 wxgf 原始流，ConvertedWxgf 表示已成功转成位图。 失败时 Success=false，原因在 Error。
    Remarks

    文件不存在、密钥不对、内容无法识别都通过返回值报告，不抛异常（内部已兜底）。 未加密的 wxgf 文件也会被识别并（按需）转码，因此可以对混合目录逐个调用。

    ExportVoice(VoiceExportOptions)

    导出一条语音消息：从明文 media_*.db 的 VoiceInfo 取 silk 数据（或直接给 .silk 文件），再转成可播放的 wav/mp3。

    Declaration
    public static VoiceExportResult ExportVoice(VoiceExportOptions options)
    Parameters
    Type Name Description
    VoiceExportOptions options

    VoiceExportOptions：

    • SilkPath：直接给原始 silk 文件（给了就跳过数据库查询）；
    • AccountDir：已解密的账号目录（或其 message/ 子目录），与 ServerId 配合从库里取；
    • ServerId：VoiceInfo.svr_id（微信服务器消息 id）；
    • OutputPath：输出文件（必填）；没有扩展名时按实际格式补 .wav/.mp3/.silk；
    • Format：wav（默认，纯托管）或 mp3（需要 ffmpeg）；
    • Log：细节日志回调。
    Returns
    Type Description
    VoiceExportResult

    VoiceExportResult：成功时 Success=true，OutputPath 为实际写出的路径， MediaType/Extension 为真实格式，SilkBytes 为原始 silk 长度； 失败时 Success=false 且 Error 说明原因（缺参数、库里没有该 svr_id、转码失败等）。
    Remarks

    缺少账号/服务器 id、silk 文件不存在、转码失败都通过返回值报告，不抛异常。 若要求 mp3 但 ffmpeg 不可用，会退化为写出 .silk 原始流并在 Log 里提示。

    ResolveImageKey(ImageKeyOptions)

    解析某账号的媒体密钥（XOR 字节 + 16 字符 AES 密钥）。

    Declaration
    public static ImageKeyResult ResolveImageKey(ImageKeyOptions options)
    Parameters
    Type Name Description
    ImageKeyOptions options

    ImageKeyOptions：

    • Path：账号路径（db_storage / wxid 目录 / 数据根目录，必填）；
    • Nickname/Wxid/PlainRoot：账号选择器，规则同 ResolveDbStorage(string, string?, string?, string?, int?)；
    • KvcommDir：手动指定 kvcomm 目录（默认自动发现 %APPDATA%\Tencent\xwechat\net\kvcomm 等）；
    • TryMemory：本地解析失败时是否再扫微信进程内存（仅 Windows，需要微信在运行）；
    • Pid：钉死某个微信进程；TimeoutSeconds：内存扫描超时，默认 60 秒；
    • Log：进度回调（每步一行），null 表示静默。
    Returns
    Type Description
    ImageKeyResult

    ImageKeyResult：成功时 Success=true，XorKey（0..255）、AesKey （16 字符）、Source（local 表示 kvcomm 侧车命中，memory 表示进程内存命中）、 TemplatePath（决定 AES key 的 V2 图片模板）、AccountDir； 失败时 Success=false 且 Error 说明原因。
    Remarks

    账号解析失败、kvcomm 未命中、内存扫描失败都通过返回值报告，不抛异常。 解析结果可用 WriteMediaKeys(string, int, string) 落盘，下次直接用 ReadMediaKeys(string) 读取， 避免重复扫描。
