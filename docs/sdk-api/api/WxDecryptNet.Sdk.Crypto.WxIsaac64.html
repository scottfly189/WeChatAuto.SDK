    Class WxIsaac64

    微信 WxIsaac64 的纯 C# 实现（ISAAC-64 变体）。

    与常见 ISAAC-64 参考实现的区别（已用真实 WASM 逐字节对齐）：

    • seed 初始化使用 coreutils isaac_seed 的 8 个常量（不是单一 golden ratio 常量）， 对 m[256] 做两轮 ISAAC_MIX；
    • refill 的第二个索引是 m[(y >> 11) & 255]（不是 >> 8）；
    • keystream 按 output[255], output[254], … 顺序、每字 8 字节 大端 输出，再按 size 截断。

    输入 key 为 XML 中的十进制字符串（stoull 语义，超出 ulong 会失败）。 生成的 keystream 与微信 WASM 模块逐字节一致，可用于朋友圈图片/视频解密，无需 Node/WASM。
