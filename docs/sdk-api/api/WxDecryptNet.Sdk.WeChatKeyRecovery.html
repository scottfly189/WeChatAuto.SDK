    Class WeChatKeyRecovery

    获取 key 门面：从运行中的微信进程恢复数据库密钥（仅 Windows x64）， 以及"昵称 / wxid → 账号目录 → db_storage"的定位辅助。

    原理：扫描 Weixin.dll 里的 32 字节 internal_db_key 掩码 + 微信进程内存里的密钥指针， 把每个候选做 XOR 解掩码后，用真实库的首页 HMAC 校验，命中即真密钥。 全程只读 DLL 与进程内存：不注入、不 Hook、不改微信内存，但杀软/EDR 可能按行为告警。

    前置条件：微信已启动并登录；本进程与微信同一权限级别（微信用管理员运行时本进程也需提权）。

    Recover(KeyRecoveryOptions)

    从运行中的微信进程恢复数据库密钥（64 位 hex）。

    Declaration
    public static KeyRecoveryResult Recover(KeyRecoveryOptions options)
    Parameters
    Type Name Description
    KeyRecoveryOptions options

    KeyRecoveryOptions：

    • Path：账号路径（必填，先经 ResolveDbStorage(string, string?, string?, string?, int?) 归一化）；
    • Nickname/Wxid/PlainRoot：账号选择器，规则同 ResolveDbStorage(string, string?, string?, string?, int?)；
    • InternalKey：手动指定 32 字节 internal_db_key 掩码，跳过 DLL 扫描（已知掩码时更快）；
    • WeChatDir：手动指定微信安装目录或 Weixin.dll 路径（自动定位失败时用）；
    • TimeoutSeconds：整个恢复过程（扫描 + 校验）的硬超时，默认 180 秒，小于 10 按 10 计；
    • Pid：钉死某个 Weixin.exe 进程；不传则跳过 --type= helper，按 WorkingSet 降序逐个尝试；
    • Log：进度回调（每个步骤一行），null 表示静默。
    Returns
    Type Description
    KeyRecoveryResult

    KeyRecoveryResult：Key 为 64 位 hex 密钥；Mode 为 raw 或 passphrase（首页 HMAC 命中的密钥形态）；Pid/ProcessName 为命中的进程； ScanMs/VerifyMs 为内存扫描与候选校验耗时；DllPath、 InternalKeyCount、MemoryCandidateCount 便于排查。
    Remarks

    这是**只读**操作，不会改变微信状态；但会遍历进程内存（单区域上限 512 MB、候选上限 512 个、 校验最多 8 线程），在企业设备上可能被 AV/EDR 拦截。

    取到密钥后建议立刻保存（一个账号一个 key，通常可长期复用）；同一账号换机/重装后若校验失败， 重新取一次即可。

    Exceptions
    Type Condition
    ArgumentNullException

    options 为 null。
    AccountResolveException

    账号/路径解析失败（见 ResolveDbStorage(string, string?, string?, string?, int?)）。
    KeyRecoveryException

    取密钥失败时抛出，消息为中文诊断，常见原因：非 Windows、微信未运行/未登录、内存中无候选、 未定位到 Weixin.dll、校验超时、找不到探针库等。

    ResolveDbStorage(string, string?, string?, string?, int?)

    把任意一种"账号路径"归一化成该账号的 db_storage 绝对路径。

    Declaration
    public static string ResolveDbStorage(string path, string? nickname = null, string? wxid = null, string? plainRoot = null, int? pid = null)
    Parameters
    Type Name Description
    string path

    可以是 db_storage、wxid_* 账号目录、db_storage 下的子目录、 或多账号的 xwechat_files 根目录（此时必须配合 nickname 或 wxid 才能选出唯一账号）。
    string nickname

    微信昵称/微信号，用于在多账号根目录下选账号。匹配来源依次为：已解密的 <plainRoot>&lt;账号>\contact\contact.db、账号 config</code> 下的明文侧车、 %APPDATA%\Tencent\xwechat\radium 的 Chromium 侧车。匹配不到会抛异常并列出候选。
    string wxid

    更可靠的账号选择器：可传完整文件夹名、wxid_ 前缀或末尾 4 位后缀。
    string plainRoot

    之前解密出的账号树根目录（默认会尝试 xwechat_files 同级的 wechat-plain</code>）， 仅在按昵称匹配时用到。
    int? pid

    当前微信主进程 PID（WeChatClient.WeChatProcessID）。传了会优先按“谁持有该账号 db_storage 的文件句柄”选号，不依赖昵称/明文侧车；不确定时自动回退到 wxid / nickname。
    Returns
    Type Description
    string

    该账号的 db_storage 绝对路径。
    Remarks

    只做路径解析与少量明文文件/侧车扫描，不读进程内存，可放心在 UI 线程调用。

    Exceptions
    Type Condition
    AccountResolveException

    路径不存在、找不到 db_storage、多账号未给选择器、昵称匹配不到或有歧义时抛出； 异常消息里会带候选账号列表，便于改用 wxid。

    VerifyDatabases(string, WeChatKey)

    校验一个密钥能打开账号 db_storage 下的哪些库（只读每个库首页做 HMAC，不写文件）。
