    Class WeChatMessageContentParser

    引用消息（原生 local_type = 244813135921，即 49 + (57 << 32)）的 appmsg/refermsg 解析器。

    解析规则： 外层 <title> 是回复文字，<refermsg> 里是被引用内容；

    被引用内容按 refermsg/type 转成 [图片] / [表情] / [视频] / [语音] / [链接] ...， 嵌套引用（type=57）递归取内层 title/des/content。

    微信 XML 可能存在未转义字符，故使用正则而不是 XDocument。

    另有 NormalizeForStorage(string?, long)：把非引用 appmsg / 媒体消息的 Content 归一化成可读文本。 当前 4.x 的 appmsg 标题/URL/recorditem 只在 message_content XML；表情的 desc 可能是 base64 protobuf（本类会解码，优先 zh_cn）。packed_info_data 的 protobuf 只承载媒体 md5 / 语音转写等，媒体 md5 仍由 WeChatMessageMediaSync 在归一化之前读取。

    NormalizeForStorage(string?, long)

    写库前的 Content 归一化（图片/视频/文件/语音/表情/链接/小程序/视频号/音乐/聊天记录/位置）。

    必须在 WeChatMessageMediaSync.AttachFilePaths 之后调用：媒体路径解析依赖原始 XML 里的 md5 / CDN 字段，提前覆盖 Content 会导致 FilePath 填不出来。

    返回 null 表示保持原 Content 不变（普通文本、通话、转账/红包、引用消息、未知 appmsg 等）。
