    DecryptDatV4(byte[], int, byte[])

    V1 / V2: 15-byte header (<6sLLx = magic, aes_size, xor_size) then AES-128-ECB(pkcs7) ciphertext + optional cleartext middle + XOR tail at the end of the payload. aes_size is the unpadded plaintext length; the header round-trips it to the padded ciphertext length. Layout after the 15-byte header: AES_cipher[aes_pad] + raw_middle + XOR_tail[xor_size].
