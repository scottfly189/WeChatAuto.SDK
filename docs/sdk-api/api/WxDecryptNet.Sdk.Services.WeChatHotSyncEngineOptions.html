    FirstRunDays

    首轮（该会话/分片尚无消息水位，或该账号尚无朋友圈水位）只同步最近 N 天，默认 30。 0 表示不回补历史，只同步从启动时刻起的新数据。负数按 0 处理（引擎会打一条日志，不会抛异常）。 已有水位后只走增量，事后改此值不会回补更早的数据。 通常请在工厂启动前设置 WeAutomation.Config.FirstRunDays（WeChatConfig），由客户端传入。
