CyberOverlay

赛博朋克风格的屏幕提示框。

用于在耗时操作（例如强开 UI Tree 扫描 weixin.dll）期间，在屏幕上绘制一个 无边框、置顶、不抢焦点、不进入任务栏的半透明 HUD 提示框。

提示框运行在独立的 STA 后台线程中，拥有自己的消息循环，因此不会阻塞调用方， 也不会与 UIA 自动化线程相互干扰。

用法：

using (CyberOverlay.Show($"正在强开 pid={pid} 的微信 UI Tree 中...")) { // 执行耗时操作 }

ForceOpenUITree

强开 UI Tree。

通过向正在运行的微信(Weixin)进程的 Qt 无障碍“门控字节”写入 1，强制微信公开 UI Tree。 该工具不会启动微信、不会注入代码、不会修改内存页保护，只会写入 Weixin.dll 中 那一个已存在的 Qt 无障碍状态字节，并在写入前校验进程、模块、PE 节、扫描证据与当前字节值。

本类移植自 qt_accessibility_activator.py。

WeChatLocalPaths

本机微信自动化的数据目录（默认 %LOCALAPPDATA%\WeChatAuto）。

需要跨升级、跨安装目录保留的文件都放这里：数据库密钥缓存 wechatkey.dat、 hot-sync 暂存 hotsync-staging、媒体缓存 media-cache。

暂存 / 媒体缓存 / 朋友圈下载目录都可被配置覆盖（见 Config）， 方便 C 盘空间紧张的用户改到大容量磁盘；为空时仍用下面的默认路径。

不要把这类数据写进程序目录：安装目录可能只读（如 Program Files）， 换目录 / 覆盖升级时也会丢。默认路径一律由 LocalApplicationData 推导， 不写死盘符、用户名或绝对路径。
