    ResolveDbStorage(string, string?, string?, string?, int?)

    Resolve raw_path (+ optional selectors) to an account db_storage. An explicit db_storage / single-account path wins even when nickname / wxid / pid are passed; multi-account roots require a selector.

    When pid is given it is tried first: the running WeChat process that holds an account's db files identifies that account without needing the nickname in cleartext. On any ambiguity (no handle yet, permission, several accounts held) resolution falls back to wxid / nickname.
