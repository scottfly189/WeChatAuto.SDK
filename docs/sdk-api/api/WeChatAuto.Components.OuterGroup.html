    AddChatGroupMemberToFriends(string, List<string>, AddFriendsOptions)

    添加群聊里面的好友为自己的好友,适用于从外部群中添加好友为自己的好友 此操作为微信严风控操作，因为微信对于一天加好友应该有数量限定，建议分批次加，一次不要超过20-30个，时间延长为4小时或者一天后

    Declaration

    Parameters
    Type Name Description
    string groupName

    群聊名称,可以为空，如果为空，则在本焦点群聊窗口邀请好友
    List<string> memberName

    成员名称列表,考虑风控,建议先运行GetChatGroupMemberList(string)获取群聊的成员列表，然后分批增加
    AddFriendsOptions options

    好友选项，可以增加好友时设置备注后缀、打招呼内容及标签等，方便分类管理
