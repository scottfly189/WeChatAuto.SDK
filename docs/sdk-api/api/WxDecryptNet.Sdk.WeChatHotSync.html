    Class WeChatHotSync

    在线热同步门面（hot-sync）：微信不用退出也能读库。

    两条路径共用旁路一致快照（.db + -wal，从不拷 -shm，拷到 db_storage **之外**的 staging，指纹稳定后才继续）：

    1. Sync(HotSyncOptions) / Watch(HotSyncWatchOptions)：staging 副本 → 页解密 → 明文镜像目录；
    2. OpenSqlCipher(HotSyncSqlCipherOptions)：staging 副本 → SQLCipher 直读（不落明文），再 Connect(string, bool) 拿连接、自写 SQL。

    默认目标集（P0）为 message/message_*.db + sns/sns.db； IncludeContact 可追加 contact/contact.db（见 ListTargets(string, bool)）。 session/session.db 不在拷贝和监视范围内。 全程只读微信目录、不写回。

    OpenSqlCipher(HotSyncSqlCipherOptions)

    hot-sync 的 SQLCipher 直读入口：解析账号后返回会话；不产生明文库。

    调用方再 Connect(string, bool)：每次 Connect 都会旁路一致拷贝该库到 staging，用 SQLCipher 解锁，并把连接交给调用方。连接默认只读、Pooling = false； Dispose 后文件锁释放，才能对该库再次 Connect（重新拷贝）。

    原有 Sync(HotSyncOptions) / Watch(HotSyncWatchOptions)（staging → 解密明文目录）保持不变。

    Sync(HotSyncOptions)

    跑一轮热同步：一致拷贝 + 解密，把结果镜像到输出目录（一次性，不循环）。

    Declaration
    public static HotSyncResult Sync(HotSyncOptions options)
    Parameters
    Type Name Description
    HotSyncOptions options

    HotSyncOptions：

    • Path：账号路径（db_storage / wxid 目录 / 数据根目录，必填）；
    • Key：32 字节密钥（必填）；
    • OutputDir：镜像输出根目录（必填），其下自动建账号子目录；
    • IncludeContact：是否额外同步 contact.db；
    • Retries/RetrySleepSeconds：单库一致拷贝的最大重试次数与间隔；
    • StagingDir：自定义 staging 根目录（必须位于 db_storage 之外；null 时用输出目录下的临时子目录）；
    • Only：只同步这些源文件路径（覆盖默认目标选择）；
    • Progress：进度回调 (已完成, 总数, 源路径, 是否成功, 失败原因)。
    Returns
    Type Description
    HotSyncResult

    HotSyncResult：Mode 为 once；Status 为 success/partial/error； Files 为逐文件明细（CopyAttempts 反映一致拷贝重试了几次，DecryptMs 为解密耗时）。
    Remarks

    单个文件失败不会中断整批：结果里 Failed > 0、Status 变为 partial， 失败原因在对应 Message。 快照只是"拷贝那一瞬间"的一致状态；微信持续写入时，不同库之间不保证同一时刻。

    Watch(HotSyncWatchOptions)

    持续热同步（watch）：先做一次全量同步，然后轮询目标库；某个库变化后等它"安静" DebounceSeconds 再重新同步，直到 ShouldStop 返回 true 或达到 MaxCycles。

    Declaration
    public static HotSyncResult Watch(HotSyncWatchOptions options)
    Parameters
    Type Name Description
    HotSyncWatchOptions options

    HotSyncWatchOptions（在 HotSyncOptions 基础上增加）：

    • DebounceSeconds：脏库需要保持安静的时长（去抖），默认 0.75 秒；
    • PollIntervalSeconds：轮询间隔，默认 0.5 秒；
    • ShouldStop：每个周期检查一次，返回 true 即退出（用于 Ctrl+C / 关闭窗口）；
    • MaxCycles：最多跑多少个轮询周期（主要给测试用）；null 表示一直跑到 ShouldStop。
    其余参数同 Sync(HotSyncOptions)。
    Returns
    Type Description
    HotSyncResult

    HotSyncResult：Mode 为 watch；Cycles 为实际轮询周期数； TotalEvents 为累计同步事件数（首轮全量 + 后续增量）； Success/Failed 是事件计数而不是文件数；Files 为全部事件明细。
    Remarks

    这是**阻塞**调用：请在后台线程运行，并用 ShouldStop（配合 CancellationToken） 或 MaxCycles 控制退出，否则会一直轮询。

    注意：ShouldStop 与 Progress 都会在轮询线程上被调用，回调里不要做长耗时操作。

    Type Condition
    ArgumentNullException

    options 为 null。
    FileNotFoundException

    路径不存在或找不到 db_storage。
    InvalidOperationException

    staging 目录落在 db_storage 内部时抛出。
