    Class VoiceAsr

    本地语音转写（ASR）后台队列。

    设计约束（与 hot-sync 链路解耦）：

    • 只在**增量**轮次入队：首轮同步不转写，避免拖慢首轮（见 DecryptAfterUpsert(allowVoiceAsr)）；
    • 入队只是 TryWrite(T)，永不阻塞读取/UPSERT/水位推进；
    • 转写在独立后台线程（BelowNormal、单并发）执行，异常全部吞掉并记日志；
    • 只回写 wechat_message.Content 一列，失败保持 [语音]，不重试、不改其他字段。

    模型由用户自行下载：Config 的 AsrModelDir 下放 model.int8.onnx（或 model.onnx）与 tokens.txt。 模型缺失/加载失败时本模块静默禁用，不影响 SDK 任何其他功能。

    ReportStatus()

    输出一条「语音转写当前状态」日志（每个进程/配置组合只输出一次）。

    目的：ASR 是默认关闭的可选功能，若用户漏配，原来日志里毫无线索，只能看到 [语音]。 启动时明确告诉用户：未启用 / 已启用但模型缺失 / 已启用及模型路径与是否含首轮。
