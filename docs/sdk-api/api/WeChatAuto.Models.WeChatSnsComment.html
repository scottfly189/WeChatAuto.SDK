    Class WeChatSnsComment

    朋友圈评论中间表。完整名单来自 SnsTimeLine.content XML 的 comment_user_list（条目 type 一律为 2）。 同一条若在 SnsMessage_tmp3.serialized_comment_buf 有包，重叠字段 （发起人、对象、类型、时间、正文、comment_id、flag）以 protobuf 为准；名单本身不在包里，仍以 XML 列表为准。 回复的父评：serialized_ref_buf 为完整包时，父评正文与发起人优先用包；否则用 XML 的 ref_comment_id / ref_username。
