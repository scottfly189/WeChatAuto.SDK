群成员中间表：成员名单、群名片、邀请人来自原生 chat_room.ext_buffer。 群名称、群主/成员/邀请人的微信昵称或备注请按 RoomUsername / Owner / MemberUsername / Inviter 关联 wechat_contact（Remark 优先，空则 NickName）；本表不维护这些显示名快照。 支持多微信聚合。
