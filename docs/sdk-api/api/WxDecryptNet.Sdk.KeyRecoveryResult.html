    DatabaseChecks

    逐库校验结果：这个密钥能打开 db_storage 下的哪些库。

    只读每个库的首页做 HMAC 校验（毫秒级），不影响取密钥流程。 微信某些版本对每个库使用独立密钥，或升级后结构变化时，会出现「部分库打不开」—— 有了这份清单，可以在启动日志里明确告警，而不是等到同步阶段发现数据缺失。
