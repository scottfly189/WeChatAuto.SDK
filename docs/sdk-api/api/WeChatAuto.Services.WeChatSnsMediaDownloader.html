朋友圈图片 / 视频「旁路」下载器（默认不启动）。

旁路：hot-sync 主链路只有 1~2 秒预算，下载是外网 I/O，不能放进同步循环。 这里用独立定时器 + 独立 DB 连接，按 wechat_sns_media 的待处理行慢慢消化； 下载器整个挂掉也只影响媒体文件，不影响消息 / 联系人 / 群成员 / 朋友圈数据同步。

加密：朋友圈图片 / 视频是 Isaac64 流加密。图片看响应头 X-Enc， 视频看前 8 字节是否有 ftyp；解密由纯 C# WxDecryptNet.Sdk.Crypto.WxIsaac64 完成， 无需 Node / WASM，也没有额外的模块安装步骤。

幂等：每行 DownloadStatus / DownloadAttempts 落库： 成功 1，永久失败（token 过期 / 404 / 不是图片 / 缺 key）2 不再重试，非媒体 3 跳过。 动态内容变化时媒体行按 tid 重建，(Url, UrlToken, UrlKey) 未变则保留下载状态。

开关：WeChatConfig.DownloadSnsImages，默认 false。
