    Class WeChatAccountHotSyncEngine

    单账号后台同步引擎：加密库 → 旁路一致拷贝 staging → SQLCipher 直读 → 水位增量 UPSERT 中间表。 每个 WeChatClient / 账号应持有独立实例（独立 staging 与 WeChatDatabase 生命周期）。 只读微信侧，绝不写回原生库。SQLCipher 连接必须在再次拷贝 staging 之前 Dispose。

    Remarks

    不使用 FetchMessagesByUsername(string, string?, bool) 做全量拉取： 它没有水位/时间窗过滤，且会按会话反复 Connect 同一分片（每次 Connect 都会重新拷贝）。 本引擎按分片一次 Connect，在 SQL 里用 sort_seq 水位（首轮叠加 create_time 窗口）增量查询， 解码与 Name2Id 解析方式与 FetchMessagesByUsername 相同。

    Dispose()

    停止后台循环，并在工作线程退出后再 Dispose WeChatDatabase。 最多等待 WxDecryptNet.Sdk.Services.WeChatAccountHotSyncEngine.DisposeWaitTimeout（5 秒）。超时不在 Dispose 线程上抢关会话， 以免打断 staging 拷贝或仍被占用的 SQLCipher 连接；由工作线程自行释放。 只读微信侧，绝不写回原生库。
