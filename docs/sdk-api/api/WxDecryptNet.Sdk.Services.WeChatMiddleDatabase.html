    ReplaceSnsMediaBatch(SqlSugarClient, string, IReadOnlyCollection<long>, IReadOnlyList<WeChatSnsMedia>)

    用一批动态当前的完整媒体列表替换中间表里的旧行（按 tid 先删后插）。 媒体只会随 content 一起变化，因此只在 content 哈希变化 / 新帖时调用。
