    Class WeChatSnsMedia

    朋友圈媒体中间表：一条动态可以有多张图 / 多个视频（含 LivePhoto 的视频段）。 数据来自 SnsTimeLine.content 的 ContentObject/mediaList/media，按 (Tid, Idx) 唯一。

    URL 是带 token 的 CDN 地址，会过期；LocalPath 预留给后续的媒体下载/缓存。

    视频号（finderFeed）的媒体列表结构与朋友圈 media 不同，暂不写入本表，见 FinderKind / FinderId。
