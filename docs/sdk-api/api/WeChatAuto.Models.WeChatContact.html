微信联系人,对应微信联系人表 Contact 支持多微信聚合。差异同步业务键：FromWechatWxId + UserName（对应原生 contact.username）。

[SugarIndex("index_nickname", "NickName", OrderByType.Asc, false)]
[SugarIndex("index_remark", "Remark", OrderByType.Asc, false)]
