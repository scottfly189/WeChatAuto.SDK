    Class WxVoice

    语音（silk）处理：定位明文 media_N.db 分片、按 svr_id 取 silk、识别音频格式， 并在 silk / wav / mp3 之间转换（silk→wav 优先用捆绑的原生 silk-v3-decoder 与 NAudio；Python pilk 为次级回退；wav→mp3 可选依赖 ffmpeg；缺失时软失败）。

    TryDecodeSilkToWavFile(string, string, Action<string>?)

    用捆绑的 silk-v3-decoder 把 silk 文件解成 PCM，再用 NAudio 写成 16bit 单声道 WAV。 不依赖 Python / pilk / ffmpeg。解码器缺失或转换失败时返回 false（软失败，不抛异常）。 若首轮失败且文件带微信常见的前导 0x02，会去掉该字节再试一次。
